The bisection method for scalar equations

We consider a general scalar equation,

f⁢(x)=0.

We need to find x satisfying this equation

Suppose an interval [a,b] is given, and function f⁢(x) is continuous on the interval, and has opposite signs at x=a and x=b. The graph of f⁢(x), being continuous from x=a to x=b, must cross the x-axis at some point, which then is a root of f⁢(x). Not knowing where exactly is the root, we simply take the middle point between a & b, call it x1, and take it as our first approximation to the root. Since it is unlikely that this point is exactly a root of f⁢(x), we check the sign of the function at this point. Based on the sign, we can use the continuity argument again to further determine whether a root is to be found to the left or to the right of this point. Repeating this process, we can narrow down the interval that a root of f⁢(x) exists in, and a sequence of points that converges to the root. The method is called the bisection method.

The continuity of the function, and hence its graph, is essential in the construction of the approximating sequence. It guarantees that, if a continuous function has opposite signs at two end points, then it must vanish at some point in the middle. This “obvious” fact is the claim of a fundamental Theorem in calculus,

Theorem 8.1.

Suppose a function f is continuous on [a,b], and f⁢(a)⋅f⁢(b)<0. Then there exists a number c∈(a,b) such that f⁢(c)=0.

The claim above is not true when the function is not continuous, as the graphs above show.

A Matlab implementation

⬇
function [y,data] = bisect(a,b,func,tol)
% bisect(a,b,func,tol), uses the bisection method to find a root of func
% in (a,b) within tolerance tol
% evaluate the function at the end points
fa = func(a);
fb = func(b);
% Check that fa and fb have opposite signs (since we implicitly assume this)
if fa*fb >= 0
error(’The function fails to satisfy f(a)*f(b)<0 for inputs a and b’)
end
% keep track of progress of algorithm
data = [0 a b fa fb b-a];
% now we can run the algorithm
it_count = 0;
while (b-a) > tol
it_count = it_count+1;
% Get the midpoint and evaluate it
xnew = (a+b)/2;
fnew = func(xnew);
% determine which interval to keep
if fa * fnew <= 0
b = xnew;
fb = fnew;
else
a = xnew;
fa = fnew;
end
datanew = [it_count a b fa fb b-a];
data = [data; datanew];
end
% The solution needs to be a number - choose the midpoint of the final interval
y = (a+b)/2;
end

Main attributes of the Bisection method:

  1. 1.

    Assume f⁢(a)⋅f⁢(b)≤0, and f⁢(x) continuous, then bisection will always return a solution.

  2. 2.

    In the case multiple roots, bisection will only return one.

  3. 3.

    The error is always cut in half by each iteration.

  4. 4.

    Each iteration involves only 1 function evaluation.
