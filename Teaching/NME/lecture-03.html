Solvability of linear systems

We consider the following system of equations,

{a11⁢x1+a12⁢x2+⋯⁢⋯+a1⁢n⁢xn=b1,a21⁢x1+a22⁢x2+⋯⁢⋯+a2⁢n⁢xn=b2,⋯⋯an⁢1⁢x1+an⁢2⁢x2+⋯⁢⋯+an⁢n⁢xn=bn.

Here x1, x2, etc. are the unknown variables, ai⁢j’s are the known coefficients, and bi’s are the known right-hand side data. In this system, the number of equations equal the number of unknowns, and system is called a square linear system. If we put all the coefficients into a matrix A, and all the unknowns and the right-hand side data into separate column vectors, 𝒙 and 𝒃, respectively, then the system can written in a compact matrix-vector form,

A⁢𝒙=𝒃.

For this system, before we start to solve it, it is important to have some qualitative information about it, such as whether it has any solution, and whether the solution is unique. We explore these issues through some illustrative examples.

Example 1.

Solve the following system of equations,

{x1+x2=1,x1−x2=2.
Solution.

Add the two equations,

2⁢x1=3⟹x1=32.

Sub. x1 back to the 1st eqn,

x2+32=1⟹x2=−12.

This system has a unique set of solns. The system is uniquely solvable.

∎

Example 2.

Solve the following system of equations,

{2⁢x1+x2=0,2⁢x1+x2=1.

The same expression can’t be equal to different values, and hence this system admits no solution at all.

Example 3.

Solve the following system of equaitons,

{2⁢x1+x2=0,4⁢x1+2⁢x2=0.
Solution.

We note that x1=0, x2=0 solves both 1st & 2nd equations, and so do

(1,−2)(2,−4)⋯⋯

This system has infinitely many solns.

The second eqn is a multiple of the first. The two eqns are actually linearly dependent.

∎

For large systems, it is often difficult to tell whether the system is uniquely solvable.

Theorem.

A square linear system A⁢x=b is uniquely solvable if any of the following is true.

  • •

    det(A)≠0

  • •

    The rows of A are linearly independent.

  • •

    The columns of A are linearly independent.

These conditions are actually equivalent.
