Lecture 17

Approximation of second order derivatives

Suppose the function f⁢(t) represents the position of a particle on a line at time t. Then the first derivative f′⁢(t) represents the changing rate of the position f⁢(t) at time t, which is physically referred to as the velocity of the particle. The second derivative, which is the changing rate of the chaning rate f′⁢(t), is physically referred to as the acceleration.

Let (xi,f⁢(xi)), 1≤i≤n, be given, and f⁢(x) is the otherwise unknown underlying function for this data set. How can we approximate the second derivative of this unknown function at, say xi, using the given data set? We assume that the data points are uniformly distributed, with spacing =h. We proceed by expanding f⁢(x) at xi:

f⁢(x)= f⁢(xi)+f′⁢(xi)⁢(x−xi)+12⁢f′′⁢(xi)⁢(x−xi)2+16⁢f′′′⁢(xi)⁢(x−xi)3
+124⁢f(4)⁢(c)⁢(x−xi)4,c between x and xi.

Set x=xi−1 and xi+1:

f⁢(xi−1)= f⁢(xi)−f′⁢(xi)⁢h+12⁢f′′⁢(xi)⁢h2−16⁢f′′′⁢(xi)⁢h3+124⁢f(4)⁢(c1)⁢h4, c1∈[xi−1,xi],
f⁢(xi+1)= f⁢(xi)+f′⁢(xi)⁢h+12⁢f′′⁢(xi)⁢h2+16⁢f′′′⁢(xi)⁢h3+124⁢f(4)⁢(c2)⁢h4, c2∈[xi,xi+1].

Add these two equations:

f⁢(xi−1)+f⁢(xi+1) =2⁢f⁢(xi)+f′′⁢(xi)⁢h2+112×12⁢(f(4)⁢(c1)+f(4)⁢(c2))⁢h4,
f⁢(xi−1)+f⁢(xi+1) =2⁢f⁢(xi)+f′′⁢(xi)⁢h2+112⁢f(4)⁢(c)⁢h4,c∈[xi−1,xi+1].

Therefore,

f⁢(xi−1)−2⁢f⁢(xi)+f⁢(xi+1)h2=f′′⁢(xi)+112⁢f(4)⁢(c)⁢h2⏟Error.

Provided that f(4) remains bounded, we have

Error=O⁢(h2),
Theorem 17.1.

Assume f is four times differentiable in an interval containing xn. Then

|f′′⁢(xn)−f⁢(xn+1)−2⁢f⁢(xn)+f⁢(xn−1)h2|=O⁢(h2).
