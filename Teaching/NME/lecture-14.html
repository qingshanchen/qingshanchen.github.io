Line of best fitting

When lots of potentially noisy data are present, it can be hopeless/pointless to try to interpolate all the data pts exactly. In this case, one can instead try to find a low-order curve that best fits the data in a certain sense.

The first technique we will learn is a simple but popular one: line of best fitting, a.k.a linear regression.

Problem statement:

Given (xi,yi), 1≤i≤n (large), find a line

y=a1⁢x+a0

which best fits the data in a certain sense.

Substitute the data points, (xi,yi), 1≤i≤n, into this equation. Regardless the values of a0 and a1, for most if not all of these points, the equation will not hold, that is,

a1⁢x1+ a0−y1≠0,most likely,
a1⁢x2+ a0−y2≠0,⋯
⋮
a1⁢xn+ a0−yn≠0,⋯

Each of these non-zero values represents the fitting error; it is the mismatch between the data point and the line.

Sketch of the general strategy

In order for determining a line of best fitting:

  • •

    Define an error out of the mis-matches.

  • •

    Find a0 and a1 s.t. the error is the smallest possible.

We define the error as the sum of the squares of the fitting errors at all the data points,

E =∑i=1n(a0+a1⁢xi−yi)2
=∑i=1n(a02+a12⁢xi2+yi2+2⁢a0⁢a1⁢xi−2⁢a0⁢yi−2⁢a1⁢xi⁢yi)
=n⁢a02+a12⁢∑i=1nxi2+∑i=1nyi2+2⁢a0⁢a1⁢∑i=1nxi−2⁢a0⁢∑i=1nyi−2⁢a1⁢∑i=1nxi⁢yi
=n⁢a02+2⁢a0⁢a1⁢∑i=1nxi⏟X+a12⁢∑i=1nxi2⏟Q−2⁢a0⁢∑i=1nyi⏟Y−2⁢a1⁢∑i=1nxi⁢yi⏟W+∑i=1nyi2⏟Z.

With X, Q, Y, W, and Z calculated from the data, the error E can be expressed more succinctly,

E=n⁢a02+2⁢X⁢a0⁢a1+Q⁢a12−2⁢Y⁢a0−2⁢W⁢a1+Z.

Written in this form, it is clear that the error E is a quadratic function of the coefficients a1 and a0.

Next, we need to find a0 and a1 s.t. E is the smallest possible. From calculus, we know that a functions achieves its minimum or maximum values at the critical points, where the first derivatives vanish.

We differentiate E against a1 and a0, and set the derivatives to zero,

∂E∂a1 =2⁢Q⁢a1+2⁢X⁢a0−2⁢W=0,
∂E∂a0 =2⁢X⁢a1+2⁢n⁢a0−2⁢Y=0.

We now have a system of two equations, from which we can solve for a1 and a0. To do so, we can write the system in the matrix-vector form,

(QXXn)⁢(a1a0)=(WY).

which can then be easily solved, e.g. in Matlab using the backslash command,

(a1a0)=(QXXn)\(WY).

The coefficients (a1,a0) found this way is a critical point of the quadratic function E; it minimizes the error E because it is a convex function with only a minimum value or no maxes. With a1 and a0, the line of best fitting is given by (1). Due to the form of the errors (sum of squares), the technique is usually referred to as the least square method.

Another approach (same underlying technique though)

One can attempt to fit all the data points with a simple line by requiring that all the (xi,yi) satisfy the equation (1). In doing so, one forms a system of equations,

{a1⁢x1+a0=y1,a1⁢x2+a0=y2,⋮a1⁢xn+a0=yn.

This system has only 2 unknowns, but n equations. With n>2, the system is over-determined. Hence, in general, an exact solution can not be found. Many software packages implement solvers that solve the system using the least square method, i.e. by finding (a1,a0) that minimizes the error defined in (2). In Matlab, this can be done by again invoking the same backslash command,

(x11x21⋮⋮xn1)⏟A⁢(a1a0)⏟x→=(y1y2⋮yn)⏟b→.
A⁢x→=b→,x→=A\b→.
