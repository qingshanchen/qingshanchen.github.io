The Finite Difference Methods

Review of Taylor series

Theorem 16.1.

A function f⁢(x) can be expressed as an infinite or a finite Taylor series of power functions around a certain point.

  • •

    If a function f is infinitely differentiable, then for any specified expansion point x0, it holds that

    f⁢(x)=f⁢(x0)+f′⁢(x0)⁢(x−x0)+f′′⁢(x0)2!⁢(x−x0)2+f′′′⁢(x0)3!⁢(x−x0)3+⋯

    for every single real number x.

  • •

    If a function f is n+1 times differentiable, then for any specified expansion point x0, for every real number x there is a number c in the interval [x,x0] such that

    f⁢(x)= f⁢(x0)+f′⁢(x0)⁢(x−x0)+f′′⁢(x0)2!⁢(x−x0)2+⋯
    +f(n)⁢(x0)n!⁢(x−x0)n+f(n+1)⁢(c)(n+1)!⁢(x−x0)n+1.

Example 1

Use Taylor’s theorem with n=2 to approximate sin⁡(x) at x=1.1, using the expansion point x0=1. Find a bound on the error using Taylor’s theorem and compare the bound to the actual error.

Solution.

Note that

sin′⁡(x)=cos⁡x,sin′′⁡(x)=−sin⁡x,sin′′′⁡(x)=−cos⁡x.

Expand sin⁡(x) around the point x0=1:

sin⁡(x)=sin⁡(1)+sin′⁡(1)⁢(x−1)+12⁢(−sin⁡1)⁢(x−1)2+16⁢(−cos⁡c)⁢(x−1)3.

For x=1.1, c∈[1,1.1],

sin⁡(1.1)= sin⁡(1)+cos⁡(1)×0.1−12⁢sin⁡(1)×0.01−16⁢cos⁡(c)×10−3,
sin⁡(1.1) ≈0.8913−16⁢cos⁡(c)×10−3,
sin⁡(1.1) ≈0.8913.
Error =|−16⁢cos⁡(c)×10−3|
=10−36⁢|cos⁡(c)|
≤10−36≈1.6667×10−4.

MATLAB gives sin⁡(1.1)=0.8912. The actual error is about 10−4, which is within the bound established by Taylor’s series. ∎

Approximation of the first derivative

Let {x0,x1,…,xN} be an equally spaced discretization of [a,b], and the spacing between the points is h. Suppose we are given values of function f at these points,

f⁢(x0),f⁢(x1),f⁢(x2),…,f⁢(xN).

Question: How can we compute/approximate f′⁢(xi) from this limited information?

Take the line segment between xi−1 and xi, and calculate the slope of the line segment:

slope=f⁢(xi)−f⁢(xi−1)xi−xi−1=f⁢(xi)−f⁢(xi−1)h⏟backward difference≈f′⁢(xi).

Take the line segment between xi and xi+1:

slope=f⁢(xi+1)−f⁢(xi)xi+1−xi=f⁢(xi+1)−f⁢(xi)h⏟forward difference≈f′⁢(xi).

Important question: How accurate are these approximations?

Expand f⁢(x) at xi:

f⁢(x)=f⁢(xi)+f′⁢(xi)⁢(x−xi)+12⁢f′′⁢(c)⁢(x−xi)2,

c between x and xi. Set x=xi+1:

f⁢(xi+1) =f⁢(xi)+f′⁢(xi)⁢(xi+1−xi)+12⁢f′′⁢(c)⁢(xi+1−xi)2,
f⁢(xi+1) =f⁢(xi)+f′⁢(xi)⁢h+12⁢f′′⁢(c)⁢h2,
f⁢(xi+1)−f⁢(xi)h⏟FD =f′⁢(xi)+12⁢f′′⁢(c)⁢h⏟e.

Thus the approximation error by the FD method takes the form

e=12⁢f′′⁢(c)⁢h.

If f′′⁢(c) is bounded, then the relation above may be simply written as

e=O⁢(h).

The FD method is first-order accurate: e∼h.

The same holds for the backward difference formula:

Error=O⁢(h),given that ⁢f′′⁢ is bounded.
Theorem 16.2.

Let f be a twice differentiable function in an interval containing xi. Then the errors in approximating f′⁢(xi) with the forward and backward difference methods are bounded by

|f⁢(xi+1)−f⁢(xi)h−f′⁢(xi)|≤C⁢h=O⁢(h),
|f⁢(xi)−f⁢(xi−1)h−f′⁢(xi)|≤C⁢h=O⁢(h),

where C’s are constants independent of h, and depend on the value of the second derivative of f near xi.

Example 2

Use the forward difference method, with varying h, to approximate the derivative of f⁢(x)=esin⁡(x) at x=0. Furthermore, verify numerically that the error is O⁢(h).

Solution.

We note that

f⁢(x)=esin⁡(x),f′⁢(x)=cos⁡(x)⁢esin⁡(x),f′⁢(0)=1.

By the FD method,

f′⁢(0)≈f⁢(h)−f⁢(0)h=esin⁡(h)−1h≡F⁢D⁢(h).

For varying h values, the corresponding value of F⁢D⁢(h) and the approximation errors are listed below,

1 1.3158 0.3158
12 1.2303 0.2303
14 1.1228 0.1228

The method converges at the first order. ∎

The center difference method

Instead of using a forward or backward point, we can use both of them, but leave out the point at the center, xi, and this results in the center difference formula:

f⁢(xi+1)−f⁢(xi−1)xi+1−xi−1=f⁢(xi+1)−f⁢(xi−1)2⁢h⏟center difference≈f′⁢(xi).
Theorem 16.3.

Let f be a three times differentiable function in an interval containing xi. Then the error in approximating f′⁢(xi) with the centered difference approximation is bounded by

|f⁢(xi+1)−f⁢(xi−1)2⁢h−f′⁢(xi)|≤C⁢h2=O⁢(h2),

where C can be considered a constant with respect to h, and it depends on the value of the third derivative of f near xi.

Center difference is second-order accurate.

Example. Using h=1 and h=0.1, approximate f′⁢(1) with f⁢(x)=x3 using forward, backward, and centered difference methods. Note that the true solution is f′⁢(1)=3.

Solution.

We note that

f⁢(x)=x3,f′⁢(x)=3⁢x2,f′⁢(1)=3.
