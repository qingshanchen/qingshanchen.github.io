Lecture 15

Curve of best fitting

In the last lecture we learned that, given (xi,yi), 1≤i≤n (large), a line

y=a0+a1⁢x,

of the best fitting can be found.

A straight line captures the trend in this noisy data set pretty well.

However, there are many cases where a line may not be the best choice. For example,

Clearly, for this data set, a curve does a better job than a straight line.

In this lecture, we add three more choices of curves,

  1. 1.

    exponential, y=b⁢em⁢x;

  2. 2.

    inverse, y=1m⁢x+b;

  3. 3.

    power, y=b⁢xm.

For comparison, a line of best fit,

y=a0+a1⁢x,

is also controlled by two parameters, but in a different form.

So now we have four tools in the bag: line, exponential, inverse, power. Which one is the best? Of course it depends on the data set. Follow this procedure to find out the curve of best fit:

  1. 1.

    Linearize the data through a transformation. The transformation that best straightens the data points dictates which option to use.

  2. 2.

    Fit a line of best fit to the linearized data points.

  3. 3.

    Transform the line back to get a curve of best fitting.

More details on Step 1 & 3

  • •

    If suspecting exponential type,

    y=b⁢em⁢x,

    take log on both sides,

    log⁡y=log⁡b+m⁢x,

    then (x,log⁡y) should satisfy a linear relation. On the data set, if (xi,log⁡yi), 1≤i≤n, more or less fall on a straight line, then an exponential curve is the best choice.

    Transformation used: (x,y)⟶(x,log⁡y).

    Inverse transformation: let log⁡y=a1⁢x+a0 be the line of best fitting, then y=b⁢em⁢x, with m=a1, b=ea0.

  • •

    If suspecting an inverse type:

    y=1m⁢x+b,

    take inverse on both sides,

    1y=m⁢x+b,

    then (x,1/y) should satisfy a linear relation. On the data set, if (xi,1/yi), 1≤i≤n, more or less fall on a straight line, then an inverse curve is the best choice.

    Transformation used: (x,y)⟶(x,1/y).

    Inverse transformation: let log⁡1y=a1⁢x+a0 be the line of best fitting, then y=1m⁢x+b, with m=a1, b=a0.

  • •

    If suspecting a power function type:

    y=b⁢xm,

    take log on both sides,

    log⁡y=log⁡b+m⁢log⁡x,

    then (log⁡x,log⁡y) should satisfy a linear relation. On the data set, if (log⁡xi,log⁡yi), 1≤i≤n, more or less fall on a straight line, then a power curve is the best choice.

    Transformation used: (x,y)⟶(log⁡x,log⁡y).

    Inverse transformation: let log⁡y=a1⁢log⁡x+a0 be the line of best fitting, then y=b⁢xm, with m=a1, b=ea0.

Import the data:

x = 0:.25:5;

Plot the raw data points to get an idea:

⬇
plot(x,y,’rs’)

The data points follow a growing trend. This suggests two possibilities, power or exponential. Let’s examine the first possibility. We apply the transformation (x,y)⟶(log⁡x,log⁡y), and plot the transformed data:

⬇
plot(log(x), log(y), ’bs’)

It doesn’t appear to be a straight line. Try the next option, and apply the transformation (x,log⁡y):

⬇
plot(x, log(y), ’gs’)

This time, the transformed data points are more or less on a straight line. Next, find a line of best fit for this transformed data set using the method from the last lecture:

⬇
X = sum(x);
Y = sum(log(y));
Q = sum(x.*x);
W = sum(x.*log(y));
n = size(x,2);
A = [Q X; X n];
a = A\[W; Y]
⬇
a = 2x1
0.4734
-1.0759

Check that this is indeed a line of best fit for the transformed data set:

⬇
xx = 0:0.01:5;
yy = polyval(a, xx);
plot(x,log(y), ’rs’, xx, yy, ’k-’)

Now we need to get back to the original data set. The transformed data set approximately satisfy the linear relation

log⁡(y)=a⁢(1)⁢x+a⁢(2).

Take exponential on both sides: Hence y=b⁢em⁢x, where b=ea⁢(2), m=a⁢(1).

⬇
b = exp(a(2));
⬇
m = a(1);

Now plot the exponential curve along with the original data set:

⬇
yy = b*exp(m*xx);
plot(x,y,’rs’, xx, yy, ’k-’)
