Gaussian Elimination

Gaussian elimination for solving a linear system

  1. 1.

    Manipulate the system into an upper triangular matrix

  2. 2.

    Use backward substitution to find the solution.

Manipulation through three elementary row operations:

  1. 1.

    Multiplication of a row by a constant

  2. 2.

    Swap of any two rows

  3. 3.

    Replacing a row by a linear combination of that row and any other row.

In the matrix-vector form, the system reads

(014246560)⁢(x1x2x3)=(9166).

The Gaussian elimination method is typically applied to the augmented matrix of the system, which includes the coefficient matrix and the right-hand side vector,

(0149246165606)

Then basic row ooperations are carried out, step by step, to transform the coefficient matrix into an upper triangular one,

(0149246165606)→R1↔R3(5606246160149)→R2←R2+(−25)⁢R1
(560608566850149)→R3←R3+(−58)⁢R2(56060856685001412).

The coefficient matrix is now in the shape of an upper-triangular matrix, and the good and old backward substitution algorithm can now be applied to find the solution to the system,

x1=0,x2=1,x3=2.

∎

Gaussian elimination uses elementary row operations to transform the coefficient matrix into an upper-triangular matrix by eliminating all the entries below the diagonal, one column at a time, from the left to the right.

A Matlab implementation

⬇
function [x] = GaussianElimination(A,b)
n = length(b);
for k=1:n-1
% Check to see if the pivot is zero
if abs(A(k,k)) < 1e-15;
error(’A has diagonal entries of zero’)
end
% Apply transformation to remaining submatrix and RHS vector
for i=k+1:n
m = A(i,k)/A(k,k); %multiplyer for current row i
for j=k+1:n
A(i,j) = A(i,j) - m*A(k,j);
end
b(i) = b(i) - m*b(k);
end
end
% A is now upper diagonal. Use backsubstitution to solve the transformed problem.
x = BackSubstitution(A,b);

Computational cost

The procedure of using Gaussian elimination to solve a linear system of equations consists of two parts: the elimination part and the backward substitution part. The cost of the whole procedure is then the sum of the computaitonal cost of each part,

Total cost=Cost of GE?⁢?⁢?+Cost of Backward Sub.O⁢(n2)

From the last lecture, we know that the backward substitution part takes on the order of O⁢(n2) FLOPs. We now work on the computational cost for the Gaussian elimination part,

# FLOPS for GE =∑k=1n−1∑i=k+1n(1+2+∑j=k+1n2)
=∑k=1n−1[3⁢(n−k)+∑i=k+1n∑j=k+1n2]
=∑k=1n−1[3⁢(n−k)+2⁢(n−k)⁢(n−k)]
=3⁢(n−1+n−2+⋯+1)
+2⁢[(n−1)2+(n−2)2+⋯+(1)2]
=3⁢∑k=1n−1k+2⁢∑k=1n−1k2
=O⁢(n2)+2⁢(n−1)⁢(n)⁢(2⁢n−1)6
=O⁢(n2)+13⁢(2⁢n3−n2−2⁢n2+n)
=O⁢(n2)+O⁢(n3)+O⁢(n2)
=O⁢(n3).

The cost of the Gaussian elimination part is on the order of O⁢(n3) FLOPs. The total cost of solving a linear system of equation using the GE method is still O⁢(n3), because the GE part dominates in the computational cost.
