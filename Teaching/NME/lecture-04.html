Lecture 4

Solving Triangular Systems

Backward substitution

We begin with a simple example.

Example 1.

Solve the following system of equations:

x1+2⁢x2+3⁢x3 =1,
4⁢x2+5⁢x3 =−5,
6⁢x3 =−6.

This is a system of 3 equations, for 3 unknowns. In the matrix-vector form,

(123045006)⁢(x1x2x3)=(1−5−6).

The coefficient matrix is an upper-triangular matrix.

The most straightforward way of solving this system is to start with the bottom row/equation, and work our way up. From the 3rd equation,

6⁢x3=−6⟹x3=−1.

Substitute x3=−1 into the first two equations,

x1+2⁢x2+3⁢(−1) =1,
4⁢x2+5⁢(−1) =−5,

After some simplifications, we reach a reduced 2×2 system,

x1+2⁢x2 =4,
4⁢x2 =0,

which is still upper-triangular. Start from the last equation again,

4⁢x2=0⟹x2=0.

Substitute x2=0 into the first equation,

x1+2⁢(0)=4⟹x1=4.

Algorithm (Backward substitution)
A: n×n real upper-triangular matrix; b: n×1 real vector

For ⁢j=n:−1:1x⁢(j)=b⁢(j)/A⁢(j,j),for ⁢i=1:j−1b⁢(i)=b⁢(i)−A⁢(i,j)⁢x⁢(j)endend

Below is a Matlab function script implementing this backward substitution algorithm.

⬇
1 function [x] = BackSubstitution(A,b)
2 % solve the upper triangular system Ax=b using back-substitution
3
4 n= length(b);
5 x = zeros(n,1);
6
7 for j=n:-1:1
8 % Check to see if the diagonal entry is zero
9 if abs(A(j,j)) < 1e-15
10 error(‘A is singular (diagonal entries of zero)’)
11 end
12
13 % Compute solution component
14 x(j) = b(j) / A(j,j);
15
16 % Update the RHS vector
17 for i=1:j-1
18 b(i) = b(i) - A(i,j)*x(j);
19 end
20 end

We note that the backward substitution algorithm can’t continue if the diagonal entry is zero. Since the floating-point representation of real numbers on computers are never exact, and hence, instead of checking for zero, we check whether the diagonal entry is below a certain threshold in lines 9–11 in the code above.

To quantify the work load of an algorithm, we need a ’unit of account’, and that ’unit of account’ is provided by FLOP, which stands for Floating-point Operation. To make things simpler, each addition, subtract, multiplication, or division is counted as one FLOP. How many FLOPS does the backward substitution cost? The number of FLOPs that the backward substitution algorithm takes can be calculated explicitly,

n⁢FLOPs =∑j=1n(1+∑i=1j−12)
=∑j=1n(1+2⁢(j−1))
=∑j=1n(2⁢j−1)
=1+3+5+7+⋯+(2⁢n−1)
=2⁢n×n2=n2.

This calculation shows that n⁢FLOPS for the backward substitution algorithm is on the order of n2, that is, using the big-O notation,

n⁢FLOPS=O⁢(n2).

If the matrix size doubles, then the workload quadruples.

Forward substitution

Now, let’s consider a general system in the following form,

(a11000a21a2200a31a32a330a41a42a43a44)⁢(x1x2x3x4)=(b1b2b3b4).

The coefficient matrix is a lower-triangular matrix. The most straightforward way to solve this system is to start with the first row, and work our way down. This procedure is naturally called the Forward Substitution Algorithm.

Again, the diagonals need to be non-zero for the algorithm to work.
