LU Factorization

We consider a general linear system of equations,

A⁢x=b.

Here

A n×n⁢ matrix,
b,x length−n⁢ column vector.

Gaussian elimination can be applied, the cost of which is

# of FLOPs=O⁢(n3).

When b changes, the whole process needs to be repeated, step by step, which seems wasteful and unnecessary.

LU Factorization (What & Why)

The LU factorization technique seeks to write the coefficient matrix as the product of two matrices, one lower-triangular, and the other upper-triangular, that is,

A=LLower triangularn×nUUpper triangularn×n

Replacing A by L⁢U in the equation,

L⁢U⁢x⏟y=b.

Denote the column vector U⁢x by y for now. The above equation then can be written as

L⁢y=b.

This is a lower triangular system, and the Forward Substitution algorithm can be applied to find y. Once y is known, the equaiton

U⁢x=y

can be solved for x. This is an upper triangular system, and the backward substitution, the first algorithm learned in this chapter, applies.

The main advantage of the LU factorziation technique is that once L and U factors have been found for a given coefficient matrix A, they can be re-used again and again, for any given right-hand side vector b.

LU Factorization (How)

Here we will only consider the case where no swapping (pivoting) is needed. GE reduces the coef. matrix A into an upper triangular matrix. We call this upper-triangular matrix U. What about L? We form L matrix from GE. The lower-triangular matrix L, by convention, has ones on the diagonal, with each of its sub-diagonal entry equal to the negative of the corresponding factor used in the Gaussian elimination, that is,

L=
Example 1.

Compute the LU factorization of

A=(1234)
Solution.

Applying Gaussian elimination to the matrix to transform it into an upper-triangular matrix,

(1234)→R2←R2+(−3)⁢R1(120−2)⏟U

The resulting upper-triangular matrix is the U matrix. The L matrix is given by

L=(1031).

To verify that the L and U do form a factorization of the matrix A, we can carry out the multiplication,

L⁢U=(1031)⁢(120−2)=(1234)=A

Verified. ∎

Example 2.

Compute the LU factorization of

A=(2−1111−1201).
Solution.

By the Gaussian elimination,

(2−1111−1201)→R3←R3+(−1)⁢R1R2←R2+(−12)⁢R1(2−11032−32010)→R3←R3+(−23)⁢R2(2−11032−32001)⏟U

The lower-triangular matrix L is thus formed as

L=(10012101231)

∎

Cost consideration

Solving a n×n linear system of equations using the LU factorization involves one factorization step, one forward substitution, and one backward substitution, with each step costing

LU factorization, same as for GE:O⁢(n3)Forward sub.:O⁢(n2)Backward sub.:O⁢(n2)

For n large, the LU step is the most expensive, and is the dominant portion of the computational cost. Thus, solving an n×n linear system using the LU factorzation costs O⁢(n3) FLOPs, the same as Gaussian Elimination.

What about finding the inverse A−1 of the matrix A? How about using the neat Crammer’s rule A−1=a⁢d⁢j⁢(A)det(A)? This formula requires O⁢((n+1)!) operations. For n=10,

  • LU: ≈860 FLOPs

  • Crammer’s: 39,916,800 FLOPs

There is a better way to find the inverse, one that is possible to do, but still offers no advantage at all compared with the LU factorization. Finding the inverse is the same as solving the matrix equations

A⁢X=I,

where X is a n×n matrix to be found, and I is the n×n identity matrix. Write both I and X as vectors of column vectors,

I=[e1,e2,⋯,en]
X=[x1,x2,⋯,xn].

Then finding the inverse X=A−1 of A is the same as solving a sequence of n systems of n×n linear systems of equations,

A⁢xk=ek,1≤k≤n.

Assuming that the LU factorization is used to solve these systems. The LU factorization of matrix A only needs to be done once, which takes O⁢(n3) FLOPs. Since there are n systems, each with a different right-hand side vector ek, both the forward substitution and backward substitution have to be repeated n times. Hence, for finding A−1,

Total number FLOPs =“LU”+n×“Forward sub.”+n×“Backward sub.”
≈O⁢(n3)+n×n2+n×n2
≈O⁢(n3)with a bigger coefficient.

The above explains why it is almost never a good idea to find A−1 in numerical computations.
