Data interpolation

Problem Given data points (x1,y1),(x2,y2),…,(xn,yn), find a function f⁢(x) s.t. yi=f⁢(xi) for 1≤i≤n.

Why would one want to do that?

  • •

    Interpolation between the data pts,

  • •

    Taking derivatives or integrals.

Interpolation by a single polynomial

Give n data points (xi,yi), 1≤i≤n, find a single polynomial interpolant.

Use polynomials.

y⁢(x)=c0+c1⁢x1+c2⁢x2+c3⁢x3+⋯+cn−1⁢xn−1

This function needs to pass through all the data pts,

{c0+c1⁢x1+c2⁢x12+⋯+cn−1⁢x1n−1=y1,⋮c0+c1⁢xn+c2⁢xn2+⋯+cn−1⁢xnn−1=yn.

This a n×n linear system for C→=⟨c0,c1,c2,…,cn−1⟩. The matrix-vector form of this system

(1x1x12⋯x1n−11x2x22⋯x2n−11x3x32⋯x3n−1⋮⋮⋮⋮1xnxn2⋯xnn−1)⏟A⁢(c0c1c2⋮cn−1)⏟C→=(y1y2y3⋮yn)⏟y→.
A⁢C→=y→

Coefficient matrices generated this way from a list of points {x1,…,xn} are known as the Vandermonde matrices. This system of equations of the coefficients c0,c1,…,cn can be solved by any of your favorite method, or, in Matlab, simply by

C→=A\y→.

For a distinct set of data pts (all x’s are different), the coefficient matrix A is non-singular, i.e. det(A)≠0, and the linear system always yield a unique soln for C→. Once the coefficients ck’s are known, they can be used to construct the polynomial via (1).

Example 1

Find a polynomial interpolates the five points

(0,1),(1,2),(2,2),(3,6),(4,9).
Solution.

Below is a Matlab script for constructing and solving the linear system of the coefficients of the interpolating polynomial,

⬇
% x and y values of the 5 points to interpolate:
px = [0 1 2 3 4];
py = [1 2 2 6 9];
n = length(px);
% build nxn matrix column by column
A = zeros(n,n);
for i=1:n
A(:,i) = px.^(i-1);
end
% now solve for the coefficients:
c = A\py’;
% output matrix and coefficients:
A
c
% plot the points and the polynomial at the points x
x = linspace(-1,5,100);
y = c(1) + c(2)*x + c(3)*x.^2 + c(4)*x.^3 + c(5)*x.^4;
plot(px,py,’rs’,x,y,’k’)

In this last example, while all data points are interpolated exactly by this polynomial curve, the curve itself is very oscillatory near both ends, and exhibits steep slopes and extreme values that cannot be inferred from the dataset. This highly oscillatory behavior is a consequence of the high degree of the resulting polynomial (degree 9).
