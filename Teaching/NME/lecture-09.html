Lecture 9

The Newton method

How does it work?

The Newton method stems from the observation that around one point on a function curve, the tangent line through the same point furnishes a pretty good approximation to the curve. Here is how this observation leads to a famous and highly efficient numerical method for finding function roots. Suppose one needs to find the root of the function f⁢(x), i.e. to solve the equation

f⁢(x)=0.

Suppose this function has root at x∗. Not knowing where this true root is, one starts with an initial guess x0. The point (x0,y0=f⁢(x0)) is located on the curve of f⁢(x). Draw a tangent line to the function curve through the point (x0,y0). This tangent line goes closely along the function curve, especially near the point (x0,y0), and, assuming that this tangent line is not flat, it will intersect with the x-axis at some point, which we denote as x1. Suppose that the curve of f⁢(x) and this tangent line remain close, then x1 should be a good approximation to the true root x∗, hopefully better than the initial guess x0. Now using x1 and the corresponding value y1=f⁢(x1) as the starting point, the above steps can be repeated to find a second approximation x2 to the true soluton, and then another one x3, so on and so forth. A whole sequence of approximations can be generated this way, which, hopefully, will converge to the true root x∗.

The above is a general description of the Newton method for finding roots of nonlinear equations. Now let’s work out the mechanics of it. Suppose the kth approximation has been found. Start from (xk,f⁢(xk)), the tangent line to the function curve is given by the equation

y−f⁢(xk)x−xk=f′⁢(xk),

or equivalently,

y=f⁢(xk)+f′⁢(xk)⁢(x−xk).

To find the intersection, of the tangent line with the x-axis, we set y=0 in the equation, and solve for x,

0=f⁢(xk)+f′⁢(xk)⁢(x−xk)

Denoted as xk+1, the root is given by

xk+1=xk−f⁢(xk)f′⁢(xk)

The Newton method is embodied in this iterative formula, which, from xk, yields xk+1.

Algorithm

Given f, f′, tol, x0,

while ⁢|xnew−xold|>tol:
xold=xnew
xnew=xold−f⁢(xold)f′⁢(xold)

Code

⬇
function [root,numits] = newt(fun,funderiv,x0,tol)
% solve the equation fun(x)=0 using Newton’s method with starting
% value x0 up to the tolerance tol. ’funderiv’ is the derivative of
% ’fun’
xold=x0+1; % initialize to something other than x0 to enter loop
xnew=x0;
numits = 0;
while ( abs( xnew - xold ) > tol )
% perform the Newton iteration
fxnew = fun(xnew);
fprimexnew = funderiv(xnew);
numits = numits+1;
xold = xnew;
xnew = xnew - fxnew/fprimexnew;
end
root = xnew;
end

The Newton is usually fast. So what not to like about the Newton method?

  • •

    It requires extra info about the function, i.e. the derivative

  • •

    It may fail to converge if

    • –

      the initial guess no good;

    • –

      the tangent is almost flat (f′⁢(xk) too small, see below).

Newton vs Bisection

Newton: Fast, but may fail

Bisection: Reliable, but can be slow.

Practical strategy:

  • •

    Start with bisection to obtain a good initial guess

  • •

    Switch to Newton for faster convergence.
