Introduction

Numerical methods are procedures by which computer solve application problems. For most real-world problems there are no formulas and no analytical solutions. Numerical approximations by computers are often the only option available. To obtain these numerical approximations, various numerical methods are needed.

Main attributes of numerical methods:

  • •

    Accuracy (errors)

  • •

    Efficiency (cost)

  • •

    Robustness/stability

Sources of errors:

  • •

    Errors in the problem to be solved

    • *

      Errors (inaccuracies) in the mathematical model

    • *

      Errors in the input data

  • •

    Approximation errors. Such errors arise when approximation formulae are used in place of actual functions

  • •

    Round-off errors. They arise because modern computers can only represent real numbers to finite precisions. (More late)

In this course, we mainly deal with approximation errors and round-off errors. Of these two, the round-off errors are usually small, and are dominated by the approximation errors.

There are generally two basic types of measured errors. Given a quantity u and its approximation u~:

  • •

    The absolute error in u~ is |u−u~|.

  • •

    The relative error in u~ is |u−u~||u|.

Order of accuracy
Suppose a numerical method has error e corresponding to a parameter h used in the approximation. The method is said to be kth-order accurate if there exists a constant C, independent of h, such that

|e|≤C⋅hk.

This relation is often written using the big-O notation,

e=O⁢(hk).

Example 1. Suppose we have an algorithm where the error depends on the parameter h only, and for a sequence of h’s {1, 1/2, 1/4, 1/8, 1/16, 1/32}, the sequence of errors {10, 5, 2.5, 1.25, 0.625, 0.3125} results. Find the order of accuracy. What if the sequence of errors is {100, 25, 6.25, 1.5625, 0.390625, 0.09765625} instead?

Solution.

In the first case, since the error reduces by half whenever the parameter h reduces by half, the order of accuracy is 1 (linear). In the second case, the error is quartered whenever the parameter h is halved, the order of accuracy is 2 (quadratic). ∎
