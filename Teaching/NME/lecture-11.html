Newton Method for System of Equations

The Bisection method is innately developed for functions on a line, and there is no natural way to extend it to functions on higher dimensions. On the other hand, the Newton method and its variant, the Secant method, can be extended to higher dimensions. In this lecture, we learn how to solve systems of nonlinear equations using the Newton method.

First, we recall the Newton method for a single equation

f⁢(x)=0

is given by the iterative formula

xk+1=xk−f⁢(xk)f′⁢(xk).

Now we consider a system of nonlinear equations. In the most general form, such a system can be written as

f→⁢(x→)=0,

where

x→=(x1,x2,x3,…,xn),f→=(f1,f2,…,fn)

Example 1

Consider the system

{x12−sin⁡x3=0,x1+x2−x32=0,ex1+tan⁡x2=0.

In this case,

x→=(x1,x2,x3),

and

f1⁢(x1,x2,x3) =x12−sin⁡x3,
f2⁢(x1,x2,x3) =x1+x2−x32,
f3⁢(x1,x2,x3) =ex1+tan⁡x2.

 

In extending the Newton method (2) to the system of equations, the key is to do decide how to extend the derivative f′⁢(xk) in the formula. In a muti-dimensional setting, the single derviative is replaced by the Jacobian gradient,

∇f→⁢(x→k)=(∂f1∂x1⁢(x→k)∂f1∂x2⁢(x→k)⋯⁢⋯∂f1∂xn⁢(x→k)∂f2∂x1⁢(x→k)∂f2∂x2⁢(x→k)⋯⁢⋯∂f2∂xn⁢(x→k)⋯⋯⋯⁢⋯⋯⋯⋯⋯⁢⋯⋯∂fn∂x1⁢(x→k)∂fn∂x2⁢(x→k)⋯⁢⋯∂fn∂xn⁢(x→k)).

For a system of n equations for n unknown variables, the Jacobian gradient ∇f→ is a n×n matrix. The Newton method for the system (3) then takes the form of

x→k+1=x→k−(∇f→⁢(x→k))−1⁢f→⁢(x→k).

In this formula, (∇f→⁢(x→k))−1 formally represents the inverse of the Jacobian matrix ∇f→⁢(x→k). But didn’t we learn in the last chapter that it is almost never a good idea to explicitly compute the inverse of a matrix. Then how should (∇f→⁢(x→))−1⁢f→⁢(x→) be computed?

Let

y→k=(∇f→⁢(x→k))−1⁢f→⁢(x→k).
(∇f→⁢(x→k))⁢y→k=f→⁢(x→k)

y→k can be computed by solving this linear system, instead of using the inverse of the Jacobian.

In Matlab, the linear system can solved by the backslash command,

y→k=∇f→⁢(x→k)\f→⁢(x→k).

Example 2

{x13=x2,x1+sin⁡(x2)=−3.

This is a system of two eqns for two unknowns.

{x13−x2=0,x1+sin⁡(x2)+3=0.
x→=(x1,x2)
f→=(f1,f2)≡(x13−x2⏟f1,x1+sin⁡(x2)+3⏟f2)

The Jacobian matrix

J≡∇f→=(∂f1∂x1∂f1∂x2∂f2∂x1∂f2∂x2)=(3⁢x12−11cos⁡(x2)).

Starting from an initial guess x→0,

x→k+1=x→k−(3⁢(x1k)2−11cos⁡(x2k))−1⁢((x1k)3−x2kx1k+sin⁡(x2k)+3).

In Matlab,

x→k+1=x→k−(3⁢(x1k)2−11cos⁡(x2k))\((x1k)3−x2kx1k+sin⁡(x2k)+3).

Algorithm (Newton for systems)

Given F, JF, x→0, TOL,

x→n⁢e⁢w=x→0;x→o⁢l⁢d=x→n⁢e⁢w+1
while ⁢|x→new−x→old|>tol:
x→old=x→new
x→new=x→old−JF⁢(x→old)⁢F⁢(x→old)
end

Code

Below is an implementation of the Newton method for systems of equations.

⬇
function [root,numits] = newton(fun,gradfun,x0,tol)
% Solve fun(x)=0 using Newton’s method given the function and its gradient
% gradfun starting from the initial guess x0.
x0 = x0(:); % this will force x0 to be a column vector
xold = x0+1; % this needs to be ~= x0 so that we enter the while loop
xnew = x0;
numits = 0;
n = length(x0);
while norm(xnew-xold)>tol
gradfxk = gradfun(xnew);
fxk = fun(xnew);
fxk = fxk(:); % this will force fxk to be a column vector
[a,b]=size(fxk);
if a~=n || b~=1
error(’function has wrong dimension, expecting %d x 1, but got %d x %d’,n , a, b)
end
[a,b]=size(gradfxk);
if a~=n || b~=n
error(’gradient has wrong dimension, expecting %d x %d, but got %d x %d’, n, n, a, b)
end
xold = xnew;
% x k+1 = x k - (grad f(xk))^{-1} * f(xk), but implement as a linear solve
xnew = xnew - gradfxk \ fxk;
numits = numits+1;
if (numits>=100)
fprintf(’current step:\n’)
disp(xnew)
error(’no convergence after %d iterations’, numits);
end
end
root = xnew;
