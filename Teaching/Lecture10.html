Chapter 5 Solution of boundary value problems

5.1 Laplace Equation

The Laplace equation is a classic mathematical model that describes a system at equilibrium, be it a physical system, a chemical system, or a biological system. The equation reads

∂2u∂x2+∂2u∂y2=0.

Here, u=u⁢(x,y) represents a quantity of interest, and is an unknown to be sought. The equation is usually posed on a certain region, which we denote as Ω.

The differential equation itself alone can not fully determine the unknown function U⁢(x,y), or the equlibrium state of the system. To see why, let’s suppose that u=g⁢(x,y) is a function solving the equation. Then, g⁢(x,y)+c, for an arbitrary constant numberc, will also be a solution of the equation. Hence, additional conditions must be imposed in order to fully determine the unknown function u⁢(x,y). A common practice is to specify conditions for u⁢(x,y) and/or its derivatives on the boundary of the region Ω. These are called boundary conditions, and we can put them into three categories:

  1. 1.

    Dirichlet condition: the value of u is given.

  2. 2.

    Neumann condition: the value of ∂u∂n, the derivative of u in the out normal direction, is given.

  3. 3.

    Robin condition: u+α⁢∂u∂n is given.

The Laplace equation has no sense of time, and not surprisingly, it does not care what the initial state of the system is. But on a bounded domain, as we shall see later, the values of the function on the boundary can affect the equilibrium that can be reached.

Example 1. Laplace equation in a bounded domain

Find the solution to the Laplace equation on a rectangular domain (Figure 5.1),

∂2u∂x2+∂2u∂y2=0, {0<x<L,0<y<D,} (1)
u⁢(0,y)=0,u⁢(L,y)=0, 0<y<D, (2)
u⁢(x,0)=f⁢(x),u⁢(x,D)=g⁢(x), 0<x<L. (3)

Solution: Unlike what we have previously seen with algebraic or ordinary differential equations, solutions to partial differential equations like (1)–(3) can rarely be expressed in elementary function forms (x2, ex, sin⁡(x), etc.) For the problem of (1)–(3) that is posed on a domain with a simple geometry, we can try to express the solution in a different way, namely, function series. We will start with an ansatz for the soluton, which then leads us to a Sturm-Liouville problem. After solving the S–L problem using techniques from the last Chapter, we have a sequence of eigenfunctions at hand, on which we can expand our unknown functions, in a form that are similar, and in many cases dealt here, identical, to the Fourier series we learned in Chapter 1. Below, we present the solution process in detailed four steps.

Step 1. Separation of variables
On a rectangular domain, we can find the sol’n by separation of variables. We assume that

u⁢(x,y)=X⁢(x)⁢Y⁢(y). (4)

Substituting (4) into (1) yields

X′′⁢Y+X⁢Y′′=0.
−X′′⁢(x)X⁢(x)=Y′′⁢(y)Y⁢(y). (5)

The left-hand side is a function of x, and the right-hand side is a function of y, and the identity holds for arbitrary (x,y)∈[0,L]×[0,D], which can only happen if both the left-hand side and the right-hand side equal to some constant, say λ,

−X′′X=Y′′Y=λ, (6)

from which we derive that

X′′+λ⁢X=0, (7)
Y′′−λ⁢Y=0. (8)

The homogeneous boundary conditions in (2) imply for X that

u⁢(0,y)=X⁢(0)⁢Y⁢(y)=0⁢ for any ⁢0<y<D⟹X⁢(0)=0, (9)
u⁢(L,y)=X⁢(L)⁢Y⁢(y)=0⁢ for any ⁢0<y<D⟹X⁢(L)=0. (10)

The nonhomogeneous boundary conditions at y=0 and y=D do not yield any useful information for either X⁢(x) or Y⁢(y), and is unused for now.

Step 2. Solve the Sturm-Liouville problem
Equation (7) and boundary conditions (8) and (9) form a Sturm-Liouville problem for X,

{X′′+λ⁢X=0,0<x<L,X⁢(0)=X⁢(L)=0. (11)

This is a regular Sturm-Liouville problem, and it has infinite number of solutions (eigenfunctions) corresponding to infinite number of values for λ (eigenvalues). Using techniques from last Chapter, we find that problem (11) has

eigenvalues λn=(n⁢πL)2,n≥1,
eigenfunctions Xn=sin⁡(n⁢π⁢xL),n≥1.

Step 3. Solve the equation for Y
Substitute λn into (8),

Y′′−(n⁢πL)2⁢Y=0. (12)

The solutions to this equation can be found using the method of charasteristic equations (See last chapter),

Yn⁢(y)=An⁢cosh⁡(n⁢π⁢yL)+Bn⁢sinh⁡(n⁢π⁢yL).

Step 4. Assembly of the final solution
For each n≥1, the product,

un⁢(x,y)≡Xn⁢Yn=sin⁡(n⁢π⁢xL)⁢(An⁢cosh⁡(n⁢π⁢yL)+Bn⁢sinh⁡(n⁢π⁢yL))

solves the Laplace equation (1), and satisfy two of the homogeneous boundary conditions at x=0 and x=L. It is easy to see that, the sum of these products,

u⁢(x,y)≡∑n=1∞un⁢(x,y)=∑n=1∞sin⁡(n⁢π⁢xL)⁢(An⁢cosh⁡(n⁢π⁢yL)+Bn⁢sinh⁡(n⁢π⁢yL)) (13)

also solves the equation and satisfy the homogeneous boundary conditions. The coefficients can be determined using the remaining boundary conditions at y=0 and y=D, which so far haven’t been used.

Set y=0 in (13),

u⁢(x,0)=∑n=1∞An⁢sin⁡(n⁢π⁢xL)=f⁢(x).

Here, at the bottom boundary y=0, the entire equation reduces a sine series expansion of function f⁢(x), and the coefficients An can be calculated using the standard techniques for Fourier series (Chapter 2),

An⁢∫0Lsin⁡(n⁢π⁢xL)⁢sin⁡(n⁢π⁢xL)⁢𝑑x =∫0Lsin⁡(n⁢π⁢xL)⁢f⁢(x)⁢𝑑x,
An⁢L2 =∫0Lf⁢(x)⁢sin⁡(n⁢π⁢xL)⁢𝑑x,
An =2L⁢∫0Lf⁢(x)⁢sin⁡(n⁢π⁢xL)⁢𝑑x. (14)

Set y=D in (13),

u⁢(x,D)=∑n=1∞sin⁡(n⁢π⁢xL)⁢(An⁢cosh⁡(n⁢π⁢DL)+Bn⁢sinh⁡(n⁢π⁢DL))=g⁢(x).

This equation is slight more complex than the previous one, but if we view the expression involving An and Bn as a whole, and call it Cn,

Cn=An⁢cosh⁡(n⁢π⁢DL)+Bn⁢sinh⁡(n⁢π⁢DL),

then the equation takes the form

∑n=1∞Cn⁢sin⁡(n⁢π⁢xL)=g⁢(x).

Now it is clear that it still a sine series expansion, of g⁢(x) on the top boundary. The coefficient Cn can be calculated,

Cn=2L⁢∫0Lg⁢(x)⁢sin⁡(n⁢π⁢xL)⁢𝑑x. (15)

The coefficient Bn can be calculated from it, since An has already been found,

Bn=1sinh⁡(n⁢π⁢DL)⁢[Cn−An⁢cosh⁡(n⁢π⁢DL)]. (16)

To summarize, the solution to the boundary value problem (1)–(3) is given by (13), with the coefficients An and Bn given in (14)–(16). It is generally not possible to express the solution to this problem in a finite form of elementary functions, but it can be expressed in an infinite function series.

Example 2 (Neumann BC’s)

Solve the following elliptic boundary value problem, with the Laplace equation on a rectangular domain, with homogeneous Neumann boundary conditons in the x-direction,

∂2u∂x2+∂2u∂y2=0,0<x<L,0<y<D. (1)
∂u∂x|x=0=0,∂u∂x|x=L=0,0<y<D. (2)
u⁢(x,0)=0,u⁢(x,D)=f⁢(x),0<x<L. (3)

In the context of heat transfer, Dirichlet BCs represent specified temperature along the boundary, while Neumann BCs represent specified heat fluxes across the boundary. Homogeneous Neumann BCs imply that the boundary is insulated for heat. See Figure 5.2.

Solution:
Step 1. Separation of variables
As before we assume that the solution can be written as

u⁢(x,y)=X⁢(x)⁢Y⁢(y). (4)

Substitute (4) into (1), we obtain that

X′′+λ⁢X=0, (5)
Y′′−λ⁢Y=0, (6)

where λ are some constants. Substitute (4) into BCs (2),

X′⁢(0)⁢Y⁢(y)=0,X′⁢(L)⁢Y⁢(y)=0,0<y<D.

Since y is arbitrary and Y⁢(y) is expected to be a non-trivial function, then we must have

X′⁢(0)=0,X′⁢(L)=0. (7)

Step 2. Solve the Sturm-Liouville problem
Equation (5) and boundary conditions (7) form a Sturm-Liouville problem for X⁢(x). It is of a familiar type, and by techniques we learned in the last chapter, we find that the only non-trivial solutions to (5)+(7) are the eigenfunctions

Xn⁢(x)=cos⁡(n⁢π⁢xL),n≥0. (8)

Corresponding to eigenvalues

λn=(n⁢πL)2,n≥0. (9)

We note that, when n=0, λ0=0, and y0=1 is technically a non-trivial (i.e. non-zero) solution to the S–L problem.

Step 3. Solve the equation for Y
Substitute (9) into (6)

Y′′−(n⁢πL)2⁢Y=0.

If n=0, the sol’n has the general form

Y0⁢(y)=A0⁢y+B0.

For n≥1, its solutions have the general form

Yn⁢(y)=An⁢cosh⁡(n⁢π⁢yL)+Bn⁢sinh⁡(n⁢π⁢yL).

Step 4. Assemble the final solution
For each n≥0, the product Xn⁢Yn solve the Laplace equation and satisfy the homogeneous BCs of (2). For each n, in general, the product can not satisfy an arbitrary non-homogeneous BCs at y=D. But a series that is made up of the product may be able to satisfy the non-homogeneous BCs.

Thus we write

u⁢(x,y)=A0⁢y+B0+∑n=1∞[An⁢cosh⁡(n⁢π⁢yL)+Bn⁢sinh⁡(n⁢π⁢yL)]⁢cos⁡(n⁢π⁢xL). (10)

Enforce the boundary conditions in (3),

u⁢(x,0)=B0+∑n=1∞An⁢cos⁡(n⁢π⁢xL)=0,

which implies that

An=0⁢ for ⁢n≥1,B0=0. (11)

At y=D,

u⁢(x,D)=A0⁢D+∑n=1∞Bn⁢sinh⁡(n⁢π⁢DL)⁢cos⁡(n⁢π⁢xL)=f⁢(x).

Integrating both sides on [0,L] yields

A0⁢D⁢L =∫0Lf⁢(x)⁢𝑑x,
A0 =1D⁢L⁢∫0Lf⁢(x)⁢𝑑x. (12)

Multiplying both sides by cos⁡(m⁢π⁢xL) and integrating over [0,L], and remembering the orthogonality between the eigenfunctions, we have

Bm⁢sinh⁡(m⁢π⁢DL)⁢∫0Lcos2⁡(m⁢π⁢xL)⁢𝑑x =∫0Lf⁢(x)⁢cos⁡(m⁢π⁢xL)⁢𝑑x,
Bm =2L⁢sinh⁡(m⁢π⁢DL)⁢∫0Lf⁢(x)⁢cos⁡(m⁢π⁢xL)⁢𝑑x.

In summary, the sol’n can be written as

u⁢(x,y)=yD⁢L⁢∫0Lf⁢(x)⁢𝑑x+∑n=1∞Bn⁢sinh⁡(n⁢π⁢yL)⁢cos⁡(n⁢π⁢xL),

where

Bn=2L⁢sinh⁡(n⁢π⁢DL)⁢∫0Lf⁢(x)⁢cos⁡(n⁢π⁢xL)⁢𝑑x.

The superposition Principle

In each of the last two examples, there are a set of homogeneous boundary conditions, whether Dirichlet or Neumann, along one direction across the domain. The homogeneous boundary conditions allow us to form a Sturm-Liouville problem in each case, and obtain a sequence of eigenvalues and eigenfunctions, which become basis on which we build the solution to the original problem. What can we do if all the boundary conditions given are non-homogeneous?

Let us consider one simple example, with the Laplace equation with non-homogeneous Dirichlet boundary conditions on all sides of a rectangular domain (Figure 5.3),

{∂2u∂x2+∂2u∂y2=0,0<x<L,0<y<D,u⁢(0,y)=F⁢(y),u⁢(L,y)=G⁢(y),0<y<D,u⁢(x,0)=f⁢(x),u⁢(x,D)=g⁢(x),0<x<L. (1)

Because of the all-non-homogeneous boundary conditions, the procedure we laid out for Example 1 & 2 above cannot be directly applied. Instead of (1), we consider the following two problems, each of which satisfy homogeneous boundary conditions along one direction across the domain,

{∂2u1∂x2+∂2u1∂y2=0,u1⁢(0,y)=F⁢(y),u1⁢(L,y)=G⁢(y),u1⁢(x,0)=0,u1⁢(x,D)=0, (2)

and

{∂2u2∂x2+∂2u2∂y2=0,u2⁢(0,y)=0,u2⁢(L,y)=0,u2⁢(x,0)=f⁢(x),u2⁢(x,D)=g⁢(x). (3)

If u1 is a solution of (2), and u2 a solution of (3), then

u=u1+u2

satisfies the Laplace equation as well as the non-homogeneous BCs on all sides, and thus is a solution to the original problem (1). This is an application of the general superposition principle. It allows us to break down a complex problems into several simpler problems.

Each of the problems (2) and (3) can be solved using the 4-step procedure that we laid down before. It is unnecessary to repeat them here, as (2) and (3) each is very similar to Example 1 we dealt before. We will simply write down the solutions.

The solution of (2) is given by the series

4)u1(x,y)=∑n=1∞[Ancosh(n⁢π⁢xD)+Bnsinh(n⁢π⁢xD)]sin(n⁢π⁢yD), (()

with

An=2D⁢∫0DF⁢(y)⁢sin⁡(n⁢π⁢yD)⁢𝑑y,
B~n=2D⁢∫0DG⁢(y)⁢sin⁡(n⁢π⁢yD)⁢𝑑y,
Bn=1sinh⁡(n⁢π⁢LD)⁢[B~n−cosh⁡(n⁢π⁢LD)⁢An].

The solution to the problem (3) is given by the series

u2⁢(x,y)=∑n=1∞[Cn⁢cosh⁡(n⁢π⁢yL)+Dn⁢sinh⁡(n⁢π⁢yL)]⁢sin⁡(n⁢π⁢xL), (5)

with

Cn =2L⁢∫0Lf⁢(x)⁢sin⁡(n⁢π⁢xL)⁢𝑑x,
Dn =1sinh⁡(n⁢π⁢DL)⁢[2L⁢∫0Lg⁢(x)⁢sin⁡(n⁢π⁢xL)⁢𝑑x−Cn⁢cosh⁡(n⁢π⁢DL)].

The solution to the original boundary value problem (1) is given by

u⁢(x,y)=u1⁢(x,y)+u2⁢(x,y). (6)

5.2 Poisson Eq on a rectangular domain

We switch the gear in this section, and deal with the Poisson equation, which is basically the Laplace equation but with a non-zero right-hand side, reprsenting an external forcing or source. To keep things simple at first, we assume that the boundary conditions are all homogeneous, that is, zero. The problem is agian posed on a rectangular domain.

Example 1. The Poisson equation with homogeneous boundary conditions

Solve the elliptic boundary value problem

{∂2u∂x2+∂2u∂y2=f⁢(x,y),{0<x<L,0<y<D,}u⁢(0,y)=u⁢(L,y)=0,0<y<D,u⁢(x,0)=u⁢(x,D)=0,0<x<L. (1)

Solution: The basic idea for solution is to find the eigenvalue/eigenfunctions for

{∂2u∂x2+∂2u∂y2+λ⁢u=0,{0<x<L,0<y<D,}u⁢(0,y)=u⁢(L,y)=0,0<y<D,u⁢(x,0)=u⁢(x,D)=0,0<x<L, (2)

and then use these eigenfunctions as building blocks to construct the solution to the original problem (1). The eigenvalue problem (2) appears new to us, but actually it is just a two-dimensional generalization of the one-dimensional Sturm-Liouville problem that we studied in the last chapter.

Mimicking the procedure for the Laplace equations, we solve the Poisson equation with homogeneous boundary conditions also in four steps.

Step 1. Separation of variables for the eigenvalue problem
The eigenvalues problem (2) is posed on a domain with a simple geometry. This suggests that we start with the separation of variables technique, and assume that the solution can be written as

u⁢(x,y)=X⁢(x)⁢Y⁢(y).

Taking this form into the first equation of (2), we have

X′′⁢Y+X⁢Y′′ =−λ⁢X⁢Y,
X′′X+Y′′Y =−λ. (3)

Note that X′′X is a function of x, Y′′Y is a function of y. For their sum to be a constant independent of x and y, they both have to be constant. We set

X′′X=−μ, (4)
Y′′Y=−ν,, (5)

with μ and ν designating two new unknown parameter, and λ=μ+ν.

From the boundary conditions in (1) it is easy to infer the boundary conditions that X and Y must satisfy,

X⁢(0)=X⁢(L)=0, (6)
Y⁢(0)=Y⁢(D)=0. (7)

Steps 2. Solve the Sturm-Liouville problems for X and Y
Now we have two one-dimensional Sturm-Liouville problems in our hands, one for X, by (4) and (6),

{X′′+μ⁢X=0,X⁢(0)=X⁢(L)=0, (8)

and the other for Y, by (5) and (7),

{Y′′+ν⁢Y=0,Y⁢(0)=Y⁢(D)=0, (9)

Both of these Sturm-Liouville problems are in a very familiar form. From examples and exercises in the last chapter, we know that problem (8) has eigenvalues and corresponding eigenfunctions

μm=(m⁢πL)2, m≥1,
Xm=sin⁡(m⁢π⁢xL),m≥1,

and problem (9), being of the same type, has eigenvalues and corresponding eigenfunctions

νn=(n⁢πD)2, n≥1,
Yn=sin⁡(n⁢π⁢yD),n≥1.

Step 3. Assemble the solutions to the eigenvalue problem
We note that the index m for μ and X and n for ν and Y are independent of each other, and any combination of μm and νn form a possible eigenvalue for (2),

λm⁢n=μm+νn=(m⁢πL)2+(n⁢πD)2,m,n≥1, (10)

and the product of Xm and Yn provide the corresponding eigenfunction,

um⁢n⁢(x,y)=Xm⁢(x)⁢Yn⁢(y)=sin⁡(m⁢π⁢xL)⁢sin⁡(n⁢π⁢yD). (11)

Step 4. Assemble the solution to the Poisson equations (1)
We write the solution of (1) as a series,

u⁢(x,y)=∑m,n=1∞Am⁢n⁢um⁢n≡∑m,n=1∞Am⁢n⁢sin⁡(m⁢π⁢xL)⁢sin⁡(n⁢π⁢yD). (12)

Substituting this series into (1), and noticing that um⁢n is an eigenfunction satisfying (2) for λ=λm⁢n, we obtain

−∑m,n=1∞λm⁢n⁢Am⁢n⁢sin⁡(m⁢π⁢xL)⁢sin⁡(n⁢π⁢yD)=f⁢(x,y).

This is a double (two-variable) Fourier series expansion of f⁢(x,y). It is new to us, but techniques we learned in Chapter 2 for single-variable Fourier series can still be applied, one variable a time. First, we rearrange the double Fourier series as follows,

−∑m=1∞(∑n=1∞λm⁢n⁢Am⁢n⁢sin⁡(n⁢π⁢yD))⁢sin⁡(m⁢π⁢xL)=f⁢(x,y).

We set

Bm⁢(y)=∑n=1∞λm⁢n⁢Am⁢n⁢sin⁡(n⁢π⁢yD),m≥1, (13)

which is a m-index function of y. Then, the double Fourier series can be written in the form of a single-variable Fourier series, with y now treated as a parameter,

∑m=1∞Bm⁢(y)⁢sin⁡(m⁢π⁢xL)=−f⁢(x,y).

Using techniques from Chapter 2, it is now easy to determine the coefficient Bm,

Bm⁢(y)=−2L⁢∫0Lf⁢(x,y)⁢sin⁡(m⁢π⁢xL)⁢𝑑x,m≥1.

With Bm⁢(y) known, we take it back to (13). We note that the right-hand side is simply again a Fourier series, of Bm⁢(y), which we have just obtained. We use this relation to determine the coefficient Am⁢n,

Am⁢n =2D⁢λm⁢n⁢∫0DBm⁢(y)⁢sin⁡(n⁢π⁢yD)⁢𝑑y
=−4L⁢D⁢λm⁢n⁢∫0D∫0Lf⁢(x,y)⁢sin⁡(m⁢π⁢xL)⁢sin⁡(n⁢π⁢yD)⁢𝑑x⁢𝑑y,m,n≥1. (14)

To summarize, the solution to the Poisson equations (1) is given by (12), with Am⁢n given by (14), and λm⁢n by (10).

 

Next, we would like to make the problem a little more challenging, and consider the Poisson equation on a rectangular domain with non-homogeneous boundary conditons.

Example 2

Solve the elliptic boundary value problem

{∂2u∂x2+∂2u∂y2=f⁢(x,y),{0<x<L,0<y<D,}u⁢(0,y)=g⁢(y),u⁢(L,y)=h⁢(y),0<y<D,u⁢(x,0)=ℓ⁢(x),u⁢(x,D)=m⁢(x),0<x<L. (15)

Strategy #1. The lifting method

In this strategy, we first find a function, say k⁢(x,y), that satisfy all the non-homogeneous boundary conditions, that is,

k⁢(0,y) =g⁢(y), k⁢(L,y) =h⁢(y),
k⁢(x,0) =ℓ⁢(x), k⁢(x,D) =m⁢(x).

In all likelihood, this function will not satisfy the Poisson equation itself; if it does, then our job would be done! Next, we set

v⁢(x,y)=u⁢(x,y)−k⁢(x,y).

It is clear that this new function satisfy homogeneous conditions on the boundary, and the Poisson equation with a modified right-hand side,

{∂2v∂x2+∂2v∂y2=f⁢(x,y)−Δ⁢k,{0<x<L,0<y<D,}v⁢(0,y)=0,v⁢(L,y)=0,0<y<D,v⁢(x,0)=0,v⁢(x,D)=0,0<x<L.

Here,

Δ⁢k≡∂2k∂x2+∂2k∂y2

is the Laplace operator. This strategy works quite well for simple (i.e. Dirichlet type) BC’s, where it is not too hard to come up with such a function k⁢(x,y).

Strategy #2. The superposition principle

Under this strategy, we split a complex problem into several simpler ones, which we know how to deal with. Afterwards, we just need to combine the solutions of the simpler problems to obtain a solution to the original problem.

The difficulty of problem (15) arises from the fact that the non-zero forcing term on the right-hand side of the first equation, the non-homogeneous boundary conditions along the x-direction, and the non-homogeneous boundary conditions along the y-direction all appear at once. When each of these terms appear individually, we know how to deal with the problem. Hence, by the superposition principle, we should split the original problem (15) into three separate sub-problems.

The first sub-problem contains the non-zero forcing term on the right-hand side of the first equation, and homogeneous boundary conditions,

{∂2u1∂x2+∂2u1∂y2=f⁢(x,y),u1⁢(0,y)=0,u1⁢(L,y)=0,u1⁢(x,0)=0,u1⁢(x,D)=0,

The second sub-problem has zero forcing term, and non-homogeneous boundary conditions at x=0 and x=L only,

{∂2u2∂x2+∂2u2∂y2=0,u2⁢(0,y)=g⁢(y),u2⁢(L,y)=h⁢(y),u2⁢(x,0)=0,u2⁢(x,D)=0,

Finally, the third sub-problem has zero forcing term, and non-homogeneous boundary conditions at y=0 and y=D only,

{∂2u3∂x2+∂2u3∂y2=0,u3⁢(0,y)=0,u3⁢(L,y)=0,u3⁢(x,0)=ℓ⁢(x),u3⁢(x,D)=m⁢(x).

We know how to solve each one of these three problems. The sum of the solutions to these problems form a solution to the original problem,

u=u1+u2+u3.
